# Certificate Fonts

Place Google Fonts TTF files here to enable them in the certificate image generator.

Download the Regular weight TTF for each font from https://fonts.google.com:

| File | Font |
|------|------|
| `Inter-Regular.ttf` | [Inter](https://fonts.google.com/specimen/Inter) |
| `Roboto-Regular.ttf` | [Roboto](https://fonts.google.com/specimen/Roboto) |
| `OpenSans-Regular.ttf` | [Open Sans](https://fonts.google.com/specimen/Open+Sans) |
| `Lato-Regular.ttf` | [Lato](https://fonts.google.com/specimen/Lato) |
| `Montserrat-Regular.ttf` | [Montserrat](https://fonts.google.com/specimen/Montserrat) |
| `PlayfairDisplay-Regular.ttf` | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) |
| `Merriweather-Regular.ttf` | [Merriweather](https://fonts.google.com/specimen/Merriweather) |
| `Poppins-Regular.ttf` | [Poppins](https://fonts.google.com/specimen/Poppins) |
| `DancingScript-Regular.ttf` | [Dancing Script](https://fonts.google.com/specimen/Dancing+Script) |

`Arial` and `Times New Roman` are system fonts — no files needed.
Any font whose file is missing is skipped silently (canvas falls back to default).
